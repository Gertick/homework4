## ***Условие задачи***

Чтобы получить философский камень, алхимик должен смешать три ингредиента в строгой пропорции. Реакция запустится, только если масса каждого ингредиента (a, b, c) кратна трем. Запишите условие успешного запуска реакции.

## ***1. Алгоритм и блок-схема***

- ***Алгоритм***

    1. **Начало**
    2. Ввести исходные данные:
        a
        b
        c
    3. Проверить условие кратности масс трем:
        ((a % 3 == 0) && (b % 3 == 0) && (c % 3 == 0))
    4. Вывести результаты в зависимости от выполнения условия.
    5. **Конец**

```c
void homework()
{
    int a, b, c;
    puts("Введите массы элементов по порядку");
    scanf("%d", &a);
    scanf("%d", &b);
    scanf("%d", &c);

    if ((a % 3 == 0) && (b % 3 == 0) && (c % 3 == 0))

    else
    {

    }
}
```
